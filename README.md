# 🍽️ Bella Vista Restaurant Website

A simple and responsive restaurant website built using **HTML5** and **CSS3**. The website features a modern user interface with sections for Home, Menu, About, Contact, and a Reservation Form.

## 🚀 Features

- Responsive design
- Modern and clean user interface
- Navigation bar
- Hero section
- Menu section
- About section
- Contact section
- Reservation form
- Footer with social links

## 🛠️ Technologies Used

- HTML5
- CSS3
